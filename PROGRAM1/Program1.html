HTML (HyperText Markup Language) is the most basic building block of the Web.
It is used to describe a web page's appearance with (CSS) or its functionality with (JavaScript).


The HTML style attribute is used to add styles to an element, such as color, font size, and more.



Bold: The "b" tag in HTML is used to specify bold text without conveying any extra importance. Text written with the "b" tag is displayed in bold. You can do this by using the font-weight: bold property in CSS. It is a container tag that contains an opening tag, content, and a closing tag.


Italics: The "i" tag defines a part of text in an alternate voice or mood. The content inside is typically displayed in italic. The "i" tag is often used to indicate a technical term, a phrase from another language, a thought, a ship name, etc.


Underline: The "u" tag in HTML stands for underline, and it's used to underline the text enclosed within this "u" tag. This tag is generally used to underline misspelled words. This tag requires a starting as well as ending tag.
