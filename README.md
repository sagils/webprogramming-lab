## How to Run

### HTML and JavaScript Programs

Open the required HTML file in a web browser:

```text
PROGRAM1/Program1.html
```

Alternatively, use Visual Studio Code with the Live Server extension.

### PHP Programs

Run the PHP programs using a local server such as XAMPP, WAMP, or a PHP development server.

Example:

```bash
php -S localhost:8000
```

Then open `http://localhost:8000/PROGRAM.php` in a browser.
